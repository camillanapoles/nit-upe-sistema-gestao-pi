Formulário de Patente Padrão

Preencha os dados para submissão de Pedido de Patente de Invenção (PI) ou Modelo de Utilidade (MU)

1. Metadados do Pedido

PI protege lógica técnica. MU protege objetos físicos com nova forma.
0/150 caracteres
Máximo 150 caracteres. Não pode conter nomes fantasia ou marcas.
0/100 caracteres
Separe por vírgula. Mínimo 3, máximo 5 termos.

2. Resumo Técnico

0/1000 caracteres
Mínimo 100, máximo 1000 caracteres. Use linguagem técnica e objetiva.
0/4000 caracteres
Mínimo 500, máximo 4000 caracteres. Evite adjetivos qualitativos.
0/2000 caracteres
Mínimo 200, máximo 2000 caracteres. Identifique a lacuna técnica.
0/1500 caracteres
Mínimo 100, máximo 1500 caracteres. Use métricas quando possível (%).

3. Qualificação de Inventores

Mínimo 5, máximo 255 caracteres.
Use CPF para pessoa física ou CNPJ para pessoa jurídica.
E-mail para notificações do processo.
