## 🎨 COMO VISUALIZAR OS DIAGRAMAS (MERMAID)

### Método 1: Online (Mais Simples)

1. Acesse: https://mermaid.live/
2. Copie o código de um diagrama dos arquivos `.md`
3. Cole no editor esquerdo
4. O diagrama aparecerá automaticamente no lado direito

### Método 2: VS Code (Recomendado)

1. Instale a extensão "Mermaid Preview" no VS Code
2. Abra um dos arquivos `.md`
3. Clique com botão direito no código do diagrama
4. Selecione "Mermaid: Open Preview to the Side"

### Método 3: GitHub / GitLab

1. Faça upload dos arquivos para o GitHub ou GitLab
2. Os diagramas serão renderizados automaticamente no navegador

### Método 4: Notion

1. Cole o código Mermaid em uma página do Notion
2. O Notion reconhecerá e renderizará automaticamente

### Método 5: Draw.io / Lucidchart

1. Acesse: https://app.diagrams.net/
2. Vá em: Arrange > Insert > Advanced > Mermaid
3. Cole o código Mermaid
4. O diagrama será renderizado

## 📄 COMO USAR OS FORMULÁRIOS

### Formulários HTML (3)

**Arquivos:**
1. `Formulário de Patente Padrão (PI/MU)`
2. `Formulário de Software CII`
3. `Formulário de Registro de Programa de Computador (RPC)`

**Como Usar:**
1. Copie o código HTML do arquivo `FORMULARIOS_COMPLETOS.md`
2. Crie um arquivo `.html` em seu computador (ex: `formulario.html`)
3. Cole o código HTML
4. Abra o arquivo no navegador
5. O formulário será exibido com estilos, validações e contadores

**Dica:** Use um editor de texto simples (Notepad, VS Code) para editar os campos antes de usar.

### Formulários Markdown (7)

**Arquivos:**
1. `Anexo A - Relatório de Busca de Anterioridade`
2. `Anexo B - Matriz de Problema x Solução`
3. `Anexo C - Memorial Descritivo`
4. `Anexo F - Qualificação de Inventores`
5. `Termo de Cessão de Direitos`
6. `Declaração de Inventor`
7. `Autorização para Depósito no INPI`

**Como Usar:**
1. Copie o conteúdo do formulário Markdown
2. Cole em qualquer editor Markdown (Notion, Obsidian, Typora)
3. Preencha os campos entre colchetes `[ ]`
4. Imprima ou exporte para PDF

**Dica:** Você pode converter Markdown para PDF usando ferramentas como Pandoc ou Markdown PDF.

## 🚀 INICIANDO O PROJETO

### Passo 1: Visualizar os Diagramas

Comece abrindo o arquivo `DIAGRAMAS_VISUAIS_MERMAID.md` e visualizando o **Use Case Diagram** (Diagrama 1) para entender os atores e casos de uso.

## ❓ SUPORTE E DÚVIDAS

### Problemas Comuns

**Q: O diagrama não renderiza no VS Code**
A: Certifique-se de instalar a extensão "Mermaid Preview" ou "Markdown Preview Mermaid Support"

**Q: O formulário HTML não mostra estilos**
A: Certifique-se de salvar como `.html` e abrir no navegador (não no VS Code preview)

**Q: Quero modificar os diagramas**
A: Copie o código Mermaid para mermaid.live, faça as alterações, e copie de volta

**Q: Quero converter Markdown para PDF**
A: Use Typora (File > Export > PDF) ou Pandoc (comando: `pandoc arquivo.md -o output.pdf`)
